从神经元到智能体：
一部用论文写成的 AI 史

按时间串联 50 篇关键论文（★ 核心论文可进入对照原文精读），分六幕讲述。每篇标注“它解决了什么”和“它如何引出下一篇”。★ 为建议在文章中重点展开的核心必读。

给非专业读者的读论文方法（每篇都点开“快速解读”，三步就够）
  1. 先看“它在解决什么问题”——不懂问题，就看不懂答案。
  2. 再看“它怎么解决的”——这里用生活中的比喻代替公式。
  3. 最后按“导读”去翻原文——只读摘要、引言和一两张关键图，公式全部可以跳过。
写作建议：一条主线 + 三个转折
  1. 表示的进化：手工特征 → 词向量 → 上下文向量（ELMo/BERT）→ 通用序列建模（Transformer）。
  2. 规模的发现：AlexNet 证明“算力+数据”有效 → Scaling Laws 把它量化 → GPT-3 展示涌现 → Chinchilla 修正配比。
  3. 从“会说”到“会做”：InstructGPT 让模型听话 → CoT 让模型思考 → ReAct 让模型行动 → R1 用强化学习让推理自己长出来。
