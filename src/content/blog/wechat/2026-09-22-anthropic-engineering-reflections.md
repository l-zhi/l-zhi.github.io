Claude Code · Thariq 访谈

在刚刚过去的这一年里，AI Coding 正经历一场悄无声息的质变.不仅反映在了工作模式里，也反映在就业市场里.

最近，Anthropic 的 Claude Code 核心团队成员Thariq在一场内部对谈中，回顾了这一年将 AI Agent 推向前沿的真实心路。

![图片](/img/wechat/059e3d7d6a1d5ce31bccca70.webp)

当主持人问及“对明年有什么规划”时，核心工程师的回答却充满无奈：“面对当下，我们连未来两个月会发生什么都难以预料。”

过去传统软件技术的“半衰期”通常以年为单位，而如今的大模型，每两个月就在底层完成一次重构。

昨天还引以为豪的skill，在模型升级后可能就不需要了。

在新模型里一句话比以前一个几千字的skill还管用。

这群站在全球代码智能风暴眼中心的顶级工程师，究竟总结出了哪些颠覆常识的硬核真相？

## 01. 扔掉你的脚手架，技术的保质期正在归零

还记得一年前为 Agent 编写待办清单（To-do List）以防止它“写到一半就摆烂”的工程技巧吗？

在 Sonnet 3.5 时代，这种为弥补模型长程规划缺陷而生的 TodoWrite 工具。

仅仅一年后，它就被彻底淘汰了——底层的深度思考链与系统级状态记忆机制，已经毫不留情地吞噬了这些曾经的“天才设计”。

“你对自己亲手构建的工程补丁必须随时保持断舍离的心态，因为它们随时会被大模型底层的进化抹平。”

## 02. 从“盯着思维链执行”到“彻底放手让它发挥”

团队成员透露，他们如今 80% 的工作是在全天候驻留的Coding Agent（Claude Tag）中完成的。

![图片](/img/wechat/afc5bcd725770f1518a6128e.jpg)

（之前在slack中测试claude tag截图）

过去，程序员习惯像监工一样盯着每一次 Tool Call 和传参；

现在，模型在后台自主决策、异步调度、甚至跨会话调用团队产品背景与历史数据进行决策。

工程师面对的是一个有极强上下文感知的同事，而不是一个需要逐行审查的自动补全插件。

## 03. 测试期算力，重塑研发全流程

传统的人类代码审查（Code Review）常常沦为“挑两处语法小毛病以证明自己读过”。而在新范式下：

1. 大规模并发执行：模型能同时拉起数个分支地毯式扫雷；

2. 红蓝对抗：让 Agent 自主从多方视角辩驳，清洗掉绝大多数误报；

3. 人类只做决策和架构：真正需要人类介入的，退回至最顶层的系统架构、业务边界与抽象设计。

## 04. 工程师的护城河，转移到了“更高维的抽象”

你是否还留恋那些花费一整天手动调优性能、或死磕底层像素渐变的“匠人时光”？

工程师的角色正在被迫重构：从深陷微观实现的执行者，升级为定义目标与验证闭环的架构师。

从一个点子到原型，再到自动化上线监控，研发链路被极度压缩。

正如对谈所言：“软件工程从来就是一项‘关于拥抱变化’的职业。

你面对的问题层级变了，但本质依然是去解决问题。”。

程序员终于回归‘敏捷开发’的本质了。

## 05. 核心金句

1. “底层的技术每两个月就在你脚下根本性地震颤一次。你必须时刻保持无情，随时准备抛弃自己亲手写出来的Harness功能。”

2. “从紧盯每一个 Tool Call 的微操监工，到放手让 Agent 自行决定何时向你汇报——工程师真正的思维解放。是时候做点更有价值的事情了”

3. “人类代码审查的本质不是挑出三处细枝末节的拼写错误，而是把握模型尚未内化的系统边界与架构意图。”

4. “面对海量信息与潜在 Bug，唯一的置信度来源，就是把充沛的‘测试期算力’狠狠砸向用户真实的问题。”

“技术门槛的抹平并不意味着平庸，它意味着：你脑海中无论多么天马行空的想法，有生之年第一次真正变得触手可及。”
