## 01. 为什么要学习 Claude Code

我和AI结对编程写代码，差不多半年。

随着2025年底 Claude Code 突然能力提升，半年里我每个月的代码量将近10W行，而这每个月10W行的代码是我以前一年的代码量。

可能我个人代码量不足以说明问题，下面是Github（程序员的代码仓库）官方数据。

Github上的提交代码量情况（2024~2026年初），2026年预计会是2025年的10倍，这个增长非常疯狂。

![图片](/img/wechat/109ed9e5702cc6a77d858dd9.webp)

曾经大厂通过各种手段优化程序员的代码效率，大家脱一层皮，增长也就10%~20%，却被AI Coding 轻松碾压。

这其中不全是大模型的功劳，很大一部分功劳是Claude Code这套 Coding Agent，业界也称它为：Harness。

它负责把 AI 的“推理能力”真正转化为生产环境中的“可靠行动”的框架。

这半年，几乎所有做 AI 编程工具的团队，都在拿 Claude Code 当标杆——从怎么定义技能（Skill），到怎么管理上下文，大家都在追赶它，很少有人真正超过它。

Claude Code站在了 Harness 的最前沿。

既然它就是当下最强的那个，那我就在想：与其到处看别人总结的"最佳实践"，不如直接翻它的源码，看看它的设计者到底是怎么想的。

更巧的是，前段时间 Claude Code 的源码不小心流出来了。

![图片](/img/wechat/de5fc7bae736660b7c346984.png)

于是我利用业余时间，开始解读它，试着照着它重写一个出来。

代码仓库我开源了，我加了每次的调用步骤图，方便学习和理解： https://github.com/l-zhi/mcc

我的目标不只是"会用",而是把它的原理彻底梳理明白。这里面包括 Harness 最核心的几个部件：

1. 工具
2. 上下文管理
3. 记忆管理
4. 多Agent协作

我一直觉得未来各行各业都会有自己的Harness，也许工具不同，协作方式不同，但是方法论应该是可以进行复用的。

听说 Anthropic 最近也在做金融，科研，教育等纵深行业，思路跟AI Coding 的逻辑相似，通过一套行业harness，将LLM能力充分发挥出来。

![图片](/img/wechat/10766599f8322a855d184531.jpg)

（吃什么变成什么的星之卡比）

哪怕你完全没有技术背景，如果想搞懂 Vibe Coding 到底是怎么回事，或者提前布局行业harness，都可以跟着我，从最根上的代码一点点看起。

这是第一课。我们从"大脑"讲起。

## 02. 一切的起点

![图片](/img/wechat/71c42fc37bcee4da7a884c1d.jpg)

所有这些能力的源头，其实只有一样东西——大模型。

你可以把它想象成一个大脑。

这个大脑，是把人类几乎所有的文字、知识、代码"喂"进去训练出来的，喂着喂着，它就涌现出了智能。

一开始，我们只能问它点简单的：今天天气怎么样，帮我写句祝福语。

问一句，答一句，仅此而已。

![图片](/img/wechat/6fbe6ac6e10a54dc2818bb4d.png)

可人之所以能成为"生产力",靠的从来不是回答一个问题，而是能干成一件耗时更长的事儿。

写一个网站、画一幅画 —— 这些都不是一句话能搞定的，得一步一步来。

那怎么让这个大脑，也能干成一件需要很多步的长活呢？

答案是一个特别朴素的东西：循环。

## 03. 一切源于循环

人是怎么做事的？ 比如一个小朋友要搭起来4层的积木。

![图片](/img/wechat/6dca34bc75c30ed52583358d.jpg)

大脑的思路是什么样的呢？

![图片](/img/wechat/692106f8b6723b5b2ac12b45.jpg)

大模型干长活，用的是一模一样的套路，业内给它起了个名字，叫 ReAct 循环（Reasoning + Acting，边想边做），核心论文就是来自:「姚顺宇」发表的 《ReAct: Synergizing Reasoning and Acting in Language Models》

![图片](/img/wechat/3b973de7440b0b75f092ac99.png)

在 Claude Code 里，这个循环就是整个系统的"心跳"。

请求 → 执行工具 → 工具结果，思考-不够，再转一圈。转到大脑不再要求用工具、直接给出答案为止。

![图片](/img/wechat/cb4310fc406443a87937ad94.png)

这个不停转圈的过程，就是 Agent Loop，伪代码如下：

```cs
def agent_loop(messages):    while True:        // 如果工具都是用完，则退出循环        results = []        for tool in response.content:            // 调用工具        // 返回工具结果   // 将工具结果给大模型
```

理解了这个循环，你就理解了一个 AI 到底是怎么"思考—动手—再思考"的。

## 04. 光有大脑还不够，得有一副好身体

讲到这，得请出一张我很喜欢的图——《忍者神龟》里的那位大脑。

![图片](/img/wechat/278d239f94fbcf991d3b71d6.png)

（忍者神龟 朗格（Krang，克朗））

为什么是它？因为它太贴切了：一个再聪明的大脑，如果没有一副能打的身体，也只能待在原地空想。

对人来说，身体是眼睛、耳朵、手脚。对大模型来说，这副身体，就是工具。

工具，就是大脑伸向真实世界的手和眼。

有了它，大脑才能看见你电脑里的文件、跑起一段程序、改动一行代码——而不只是在脑子里干想。

Claude Code 给这个大脑配了整整40多件工具。

![图片](/img/wechat/a5cab9c4daa4eb4da627d2dd.png)

有的负责读（读文件、搜索代码），有的负责写（改文件、跑命令），还有的负责派活给"小弟"（多Agent协作）。

它们各司其职，最终完成一个长任务。

这一节主要想说说为什么开这个坑，以及最基础的什么是循环，以及循环和工具的关系。

下一节课，我再来讲讲这些工具中最核心的一个工具 Read —— 它让这个聪明的大脑有了眼睛。
