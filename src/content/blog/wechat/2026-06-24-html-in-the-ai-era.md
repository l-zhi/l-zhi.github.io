## 01. HTML突然火了

最近Claude Code 团队发布了Artifacts，通过HTML文档进行团队协作。

![图片](/img/wechat/da300fca134c1e14b7bb472b.png)

而这一切早在上个月,就已经提前预告。

2026年5月20号，Claude Code 团队发了一篇博客,标题翻译过来是——《Claude Code 写HTML,效果好得不讲道理》。

![图片](/img/wechat/ba093d340c0ecb6d4af85f8f.png)

文章发出来不到一天,推特上一群硅谷大佬集体转发点赞。

![图片](/img/wechat/f290897f4394d3af98308af2.jpg)

奇怪。

都2026年了,AI已经能直接帮你做产品、写代码、剪视频。这些站在AI最前沿的人,怎么突然集体在聊HTML?

HTML是什么?是那个90年代就有的、教科书第一章会教的、"老到不能再老"的网页技术。

他们为什么要重提一个30年前的老古董?

这篇文章,我们就聊聊这个问题。

聊完你会发现：HTML不是过去的技术,它恰恰是你和AI高效协作的未来。

## 02. HTML到底是什么? 你其实天天都在用

它 1990 年诞生,到今年 30 多岁了。

但你别觉得它老。它一直在进化。

![图片](/img/wechat/72392ef0d833f6659db1772a.jpg)

90 年代,你看的新浪、搜狐、雅虎、Facebook、亚马逊——全是 HTML。

![图片](/img/wechat/53dc571c9db81b37b3a1333f.png)

那时候它干的事还比较简单:展示内容、加点交互。

到 2010 年,HTML 升级到 HTML5,跟着移动互联网一起爆发——美团、滴滴、微信公众号、抖音的视频页,背后,全是它。

![图片](/img/wechat/a356b5d9b1969f5095542e06.png)

再到你工作里用的 Notion、飞书、甚至 PS、 Word、Excel 也都纷纷出了网页版。

![图片](/img/wechat/5162873c807040c862d4fa42.png)

OpenClaw 本身的界面是HTML。SpaceX龙飞船宇航员手指点的那块触控屏,是HTML。

特斯拉中控、智能冰箱、车载导航——背后大概率,也是HTML。

你看——互联网的发展,真离不开 HTML。

## 03. AI 为什么"非HTML不可"?

到这你应该会有个问题——

AI那么牛,什么都能做,为什么偏偏要"通过HTML"给我东西?

这一段最硬核,你认真看。

AI的本质,是大语言模型。它擅长的只有一件事:读写文本。

所以早期跟AI协作,大家用的是Markdown。因为它纯文本,语法极简,AI生成起来不费劲。

但Markdown有天花板——它只能表达文档。没有按钮,没有交互,没有界面,没有产品。

![图片](/img/wechat/0b8480e98f562ad6663cf7e8.png)

人看起来费劲。

而HTML刚好把这堵墙拆了。

它也是纯文本,AI写起来一样轻松。

但它的表达力是Markdown的几十倍——界面、交互、动效,全都能搞。

更关键的是,它已经在互联网上沉淀了30年,AI的训练数据里堆满了HTML样本。

AI写HTML,比写任何其他编程语言都熟练。

你打字,浏览器一渲染,3秒看到结果。

把这些放一起,你就明白了:

> **HTML,是目前唯一一个让AI能用"写文本"的方式,做出"能交互产品"的语言。**

它就是AI和你之间最自然的接口。

## 04. HTML非常简单，学习只需要3分钟

它的门槛低到不像编程。没有任何一门语言,能让一个零基础的人在3分钟内写出能跑的东西。HTML可以。

![图片](/img/wechat/cde059fc6e49a15e4d46e63f.png)

它是你跟AI对话的共同语言。

vibe coding、AI应用、Agent界面、AI生成的所有可视化产物,底层都是它。

学会它,不是为了去当程序员。是为了不在AI时代,被信息黑盒挡在门外。

## 05. 骨架·皮肤·肌肉:3句话讲完

你看到的所有网页,本质上由三个东西组成——

![图片](/img/wechat/3cebaaa228babac6a72d8f70.png)

HTML 是骨架。决定内容是什么:这里有个标题,这里有段文字,这里有个按钮。

CSS 是皮肤。决定长什么样:颜色、字号、布局、圆角。

JS 是肌肉。决定能做什么:点击、跳转、填表、动效。

骨架 + 皮肤 + 肌肉 = 一个活的网页。

![图片](/img/wechat/7364bf2cd8535460b99f9a1f.png)

记住这三个比喻,你已经超过99%的非程序员了。

下次AI给你一段代码,你扫一眼就知道——哦,这段定结构,这段调样式,这段加交互。

你不再是"看天书",你开始"看懂AI"。
