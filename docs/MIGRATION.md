# Astro 改造与本地验收记录

本记录由实施代理于 2026-09-22 生成，记录实际本地检查，不代表用户或孔明已经验收。

本文记录的是部署前的迁移检查。后续已完成正式上线，实际 Actions 结果及线上核验见 [部署记录](DEPLOYMENT.md)。

## 实施前确定的验收标准

1. 原仓库中的全部文章页面迁移为可编辑 Markdown，标题、日期、正文、代码、图片引用和历史标题锚点可核对。
2. 本地图片、demo 及其依赖资源完整保留，旧文章地址和归档、标签、分类地址继续生成。
3. 页面采用 AstroPaper 风格，桌面与手机可阅读，支持明暗主题、归档、标签、分页和搜索。
4. Markdown 写作命令、草稿预览和正式发布过滤可实际运行，正式构建不泄露草稿内容。
5. 可从锁文件安装并完成类型检查及静态构建，不依赖服务端渲染；具备基本 SEO、RSS、sitemap 和 404 页面。
6. CI/CD 覆盖 PR 检查、默认分支部署与构建产物，文档说明首次 Pages 配置和日常文章发布流程。
7. 交付可复查的检查脚本、迁移清单、页面截图和已知限制；不推送、合并或发布。

## 资产与迁移策略

原始 Git 提交：`5a3cfdd98dfaef9afdafe88ce2fe44dc7214b932`。

原站目录中存在 **26 个文章页面**，而归档列表展示 **20 篇文章**。所有页面分别恢复为 `src/content/blog/` 中的 Markdown，保留每个版本原有内容和地址。归档未收录的 6 个旧版本标记 `unlisted: true`，生成页面并设置 `noindex`，避免首页和订阅出现重复条目。

迁移保留 522 个资源文件，包括 `img/` 下 367 个文件、`demo/` 下 59 个文件，以及 `images/`、老 demo 可能需要的样式和脚本等。它们移至 `public/`，URL 不变。新博客页面不加载旧主题、jQuery、统计及评论插件。

原站生成目录从仓库根目录移除，构建结果写入忽略版本管理的 `dist/`。历史 HTML 留在 Git 历史中，迁移脚本通过 `git show` 读取固定提交，既不联网拉取正文，也不执行旧代码。脚本发现已有迁移清单时拒绝重复覆盖。

迁移时修复了 2022 年一篇文章把 frontmatter 渲染进正文、标题为空的问题：提取正确标题、日期和标签，保留正文与旧锚点。转换过程保留少量 HTML 强调标签以避免旧内容的嵌套强调和中文标点在 Markdown 中改变含义；关闭智能标点，保持原文与代码中的引号。可定位的旧站绝对 URL 统一为本站路径。

设计参考为 [AstroPaper](https://github.com/satnaing/astro-paper)，使用自行实现的 Astro 组件与原生 CSS，不是完整主题的直接安装。静态 HTML 搭配 CSS 和少量原生 JS；主题切换和搜索需要 JS，文章阅读不需要。
